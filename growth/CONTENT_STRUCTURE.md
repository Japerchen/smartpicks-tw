## 品牌與配比

- 定位：**科技配件 × 精選鞋款｜讓每一次選購，更有方向。**

- 未經核實，不宣稱「實測、實穿、官方推薦、保證、最便宜、最高分潤、10% 全商品適用、上飛機一定沒問題」。

## A. 影音母版：20 秒、9:16、720×1280

| 片段 | 秒數 | 要顯示的訊息 | 製作原則 |
|---|---|---|---|
| 1. Hook | 0–4 | 問題／反差：「USB-C Hub 插上去沒畫面？」 | 文字單畫面、夠短、無虛構實測 |
| 2. 重點 1 | 4–8 | 先確認來源設備能力 | 只放一個檢查點 |
| 3. 重點 2 | 8–12 | 核對商品規格或相容性 | 避免無證據性能宣稱 |
| 4. 重點 3 | 12–16 | 再查用途／使用限制 | 不推定安全認證 |
| 5. CTA | 16–20 | 「完整指南與精選商品 → SmartPicksTW」 | 不用未授權產品照或商標 |

- 畫面文字清楚、單張一句主旨；短片本體為原創知識卡，不假裝開箱、測試或拍攝實物。
- FB Reels 文案格式：`🎬 Hook／一段重點 → 📚 對應指南網址（utm_source=facebook&utm_medium=reels&utm_campaign=<slug>） → 🛒 1 筆真正相符商品聯盟連結（僅限核實） → 📌 非實測＋分潤揭露 → 2–4 hashtags`。
- YouTube Shorts：標題用疑問句／明確利益（避免虛假結論），說明中使用 `utm_source=youtube&utm_medium=shorts&utm_campaign=<slug>`；保持非實測與分潤揭露。**不要照搬 FB 的 hashtag 及 UTM。**
- 商品連結從 `index.html` 即時依 `productId` 取值，不得把舊的 `s.shopee.tw` 連結硬編入新增貼文。
- 新增題材包括 USB-C Hub 及鞋碼／楦型：只有影片原始檔實際存在、核對商品與授權之後才能安排發布。鞋款影片只提供一般尺寸資訊，非實穿。
- `growth/reels_cloud.py` 實作為五段、各四秒的原創圖卡 MP4；`reels_catalog.json` 為已核對的影音主題；`growth/reel_product_map.json` 指定商品關聯；驗證工具負責擋下不在目錄、NT$1、重複 ID、失效結構或不相符分類的推薦。

## B. Facebook 商品 POST：固定六段

1. **需求 Hook**：訪客為何需要這類商品，用問句開頭，約 1–2 行。
2. **商品主體**：真實商品名稱、品牌與商家（依 CSV 標示，不主張自己就是官方）。
3. **買前檢查 3 點**：相容性、規格／尺寸、售後／退換貨；僅用來源明示資訊。
4. **單一商品 CTA**：使用該商品於 `index.html` 的真實 `affiliate_url`；不要塞多個相似商品，避免分散點擊。
5. **網站入口**：帶 `utm_source=facebook&utm_medium=post&utm_campaign=<slug>` 的 `https://japerchen.github.io/smartpicks-tw/`。
6. **透明揭露**：「本文為商品資訊整理，非實測／實穿；部分連結為聯盟行銷，符合平台條件的購買可能使本站獲得分潤。」接 2–4 個貼題 hashtags。

## C. 來源驗證與自動排程

- 商品卡與貼文：存在於網站目錄、價格不為 NT$1、沒有禁止推廣或待核實 flags、短連結格式正確、標題支援文案；不能直接從佣金率挑選或在公開內容透露佣金。
- 特別注意：使用者親選的 CSV 已含新短連結。若歷史貼文或指南使用舊網址，請依 ID 更新到當前短連結；**已發布內容不重寫，也不宣稱自動改到蝦皮後台**。
- 影片素材須原創或具明確授權；不可截取商家照片、YouTube 影片、商標素材直接製片。
- 不擅自購買商品、加碼付費廣告或新增其他平台；免費配額包含 Facebook 與 YouTube 的已排程項目。
- 排程前先查 Metricool 時段、UUID、狀態及名額，已存在 Pending 不代表已公開；排程成功並回查後才更新 `social_automation_state.json`，再用 GitHub SHA 防止覆寫。
- 效益分三段：**曝光（FB／YT）→ 網站訪客與商品點擊（Metricool、GA4，含同意追蹤限制）→ 真實蝦皮有效訂單與佣金（僅蝦皮聯盟報表能確認）**。每週比較實際數據，再調整下一週內容，勿用觀看數當收入。
